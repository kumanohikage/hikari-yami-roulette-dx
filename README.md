# ☗ 光と闇のルーレットDX ☖

**将棋に勝ったら光、負けたら闇。運命の盤面が、いま回る――。**

将棋配信の「耐久ルール」を、パチンコ風の3D演出で盛り上げるルーレットです。
ブラウザで開くだけで動き、OBS にそのまま載せられます。

▶ **今すぐ回す: https://kumanohikage.github.io/hikari-yami-roulette-dx/**

## ルール（ここだけは絶対にぶれません）

| | 回すとき | 配信終了の確率 |
|---|---|---|
| ☀ **光のルーレット** | 将棋に**勝った**とき | **1 / 10** |
| 🌑 **闇のルーレット** | 将棋に**負けた**とき | **1 / 100** |

当たり（配信終了）かどうかは、回した瞬間に盤面のマス数から一様に抽選しています。
どんなに派手な演出が出ても、それは結果が決まった**あと**に選ばれた飾りです。確率は1ミリも変わりません。

## 演出

リーチの色、保留の色、予告の段階……そのすべてが「アツさ」を匂わせます。
何がどれくらいアツいのかは、画面には一切書いていません。打ち手の勘で感じ取ってください。

- 針の宝石が光る**保留変化**
- 駒が並んでいく**ステップアップ予告**
- **擬似連**
- 駒が画面を駆け抜ける**群予告**
- 降ってくる**役物**
- 盤が針に迫る**光リーチ／闇リーチ**、そして**PUSH**
- 止まったと思ったら……の**復活**
- 色が途中で化ける**逆転リーチ**
- 継続に止まった……はずの盤が動き出す**再始動**
- まれに訪れる**フリーズ**

すべての演出を見届けたとき、あなたの配信は終わっているかもしれません。

## 使い方

1. 上のリンクを開く（またはこのリポジトリの `index.html` をブラウザで開く）
2. 勝ったら「光のルーレット」、負けたら「闇のルーレット」を選ぶ
3. **SPIN!**

| キー | 動作 |
|---|---|
| Space / Enter | 回す・PUSH・結果を閉じる |
| 1 / 2 | 光 / 闇 を切り替え |
| H | ボタン類を隠す（配信画面用） |

**回転数** は回すたびに数えています。右上の「🔢 回転数」を押すと左上に表示され、− / ＋ で手直しでき、↺ は2回押すと 0 に戻ります（ページを開き直しても残ります）。

### OBS に載せる

配信には、比率が固定される **配信用URL** を使ってください。

| 用途 | URL |
|---|---|
| 横配信（16:9） | https://kumanohikage.github.io/hikari-yami-roulette-dx/?layout=horizontal |
| 縦配信（9:16） | https://kumanohikage.github.io/hikari-yami-roulette-dx/?layout=vertical |

配信用URLは、窓やソースの大きさが半端でも中身の比率が崩れず、余った部分は黒帯になります。
末尾に何も付けないURLは、画面いっぱいに広がる表示です（PC やスマホでそのまま遊ぶ用）。

**A. ブラウザソース（おすすめ）**

1. ソースを追加 → **ブラウザ** → URL に上の **配信用URL** を入れる
2. 幅×高さを **1920×1080**（横）または **1080×1920**（縦）にする
3. 操作するときは、ソースを右クリック → **操作**（対話）。キーボードを使うときは、開いた窓の中を一度クリックしてから押してください。日本語入力（IME）がオンだとキーが届かないことがあるので、半角英数にしておくと確実です
4. 「OBSグリーンバック」は不要です（背景を透かしたいときだけ使ってください）
5. 効果音は OBS の音声ミキサーで、このソース単独で音量を調整できます

**B. ウィンドウキャプチャ**

1. ページ右上の **🪟 横窓** / **🪟 縦窓** を押すと、配信用URLがアドレスバーの無い窓で開きます
2. OBS で **ウィンドウキャプチャ** → その窓を選ぶ
3. 窓の大きさが半端でも、中身は比率を保ったまま収まります（はみ出た分は黒帯になります）

**縦配信の配置について**

縦型ライブでは、画面の下のほうにチャットが重なります。
そのため縦配信用URL（`?layout=vertical`）では、盤・リーチ・結果の文字を上側に寄せ、下の約25%は演出用の余白にしています。
